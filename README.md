#CodeAlpha Task 2 – FAQ Chatbot

AI FAQ Chatbot developed for the CodeAlpha Internship Task 2 using Python, NLTK, TF-IDF, and Cosine Similarity.

Features

- Answers AI-related FAQ questions
- Uses TF-IDF and Cosine Similarity
- NLTK text preprocessing
- Handles unknown and empty questions
- Supports "exit" command

Technologies

- Python
- NLTK
- Scikit-learn
- TF-IDF
- Cosine Similarity
- JSON

How to Run

Install dependencies:

pip install -r requirements.txt

Run the chatbot:

python chatbot.py

Type "exit" to close the chatbot.
